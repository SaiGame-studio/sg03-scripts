⚔ Battle Flow

v3
⚙ Setup
get_card_definitions
• gọi trước khi bắt đầu battle (optional)
• trả về danh sách item definitions để client biết stats của từng card
battle_start
• validate: battle_mode (fast/normal/long) · enemy_entity_key · preset_instance_id
• check: không có session active
• resolve_enemy: game.get_entity_def_by_key(enemy_entity_key)
• check enemy deck: 25 < total_cards < 52
• verify_player_preset: 25 < deck_cards < 52
• load player_the_source (từ preset slots)
• load enemy_the_source (từ enemy.abilities · card_count mỗi ability · gán id mới)
• resolve_mode → HP: fast=4000 · normal=7000 · long=16000
• load item_defs cho tất cả cards (player + enemy)
• battle_session_create(state) → session_id
• client: alpha_source_spawn_card:N · omega_source_spawn_card:N
• next_move = "init_cards"
next_move = "init_cards"
init_cards
① alpha_init_cards
   • 3 preset cards (choose_card_1/2/3 từ alpha_preset_metadata, match by inventory_item_id)
   • 2 random cards từ alpha_the_source
   → state.alpha_hand (5 cards)  ·  client: alpha_source_to_hand

② omega_init_cards
   • 3 preset cards (choose_card_1/2/3 từ metadata.omega.metadata, match by code_name)
   • 2 random cards từ omega_the_source  ·  gán id/inventory_item_id mới
   → state.omega_hand (5 cards)  ·  client: omega_source_to_hand

③ deploy_enemy (lib_battle_entity_ai)
   • dispatch theo enemy_entity_key (goblin_shaman → goblin_shaman_deploy)
   • characters → omega_front_line (random face_up)
   • totem_pulse → omega_back_line (random face_up each)
   • xóa deployed cards khỏi omega_hand

④ client action: alpha_take_lamp
⑤ next_move = "alpha_turn"
next_move = "alpha_turn"
🔵 Alpha Turn Loop
alpha_card_deploy
• yêu cầu next_move = "alpha_turn"
• payload: hand[] · front_line[{id,face_up,slot_index}] · back_line[...]
• validate: union(hand+front+back payload) == union(alpha_hand+front+back state)
• giới hạn: tối đa 1 card mới lên front_line mỗi lượt
• reset card state (final_def, stun_remain) cho mỗi deployed card
• client: alpha_hand_to_front / alpha_hand_to_back / alpha_front_to_back / ...
alpha_attacking  × N
• yêu cầu omega_defending = true

├ defender = "omega_hp"
   • load attacker only (check trigger=false)
   • damage = attacker.base_atk · omega_hp -= damage
   • attacker.trigger = true
   • client: alpha_attack_omega_hp:id,damage,hp_remaining

└ defender = card
   ① plan: pending_attack = {attacker_id, defender_id, damage}
   ② omega react: goblin_shaman → totem_pulse defend (có thể tăng defender.final_def)
   ③ resolve: apply pending_attack.damage_dealt · nếu total_dmg > final_def → card → void
   • client: card_attack_card / card_defeated
alpha_turn_end
① reset_turn_cards: trigger=false · stun_remain-- trên tất cả cards của cả 2 field
② client action: omega_take_lamp
③ omega rút N bài ngẫu nhiên từ omega_the_source → state.omega_hand
   • client: omega_source_to_hand:id,slot × N
④ deploy_enemy (lib_battle_entity_ai · dispatch theo enemy_entity_key)
   • characters → omega_front_line (random face_up)
   • totem_pulse → omega_back_line (random face_up each)
   • xóa deployed cards khỏi omega_hand
⑤ omega_planning_to_attack → state.omega_planning
   • chọn 1 untriggered character từ omega_front_line
   • target: alpha_front_line card có final_def thấp nhất (fallback: back_line)
   • client: omega_plan_attack:attacker_id,defender_id
   • alpha_defending = true
⑥ client: alpha_take_lamp · alpha_turn_end:turn
⑦ next_move = "omega_turn"
↓ chuyển sang Omega Turn
next_move = "omega_turn" · alpha_defending = true
🔴 Omega Turn
alpha_defending_end
① thực thi toàn bộ state.omega_planning (card_attack_card × N):
   • nếu attacker không còn trên field → bỏ qua (alpha phòng thủ thành công)
   • plan: pending_attack = {attacker_id, defender_id, damage}
   • (phase 2: reserved cho alpha defend reactions tương lai)
   • resolve: apply final damage · nếu defeated → card → void
   • client: omega_card_move_back_to_holder:id / card_defeated
② clear omega_planning = {}
③ omega_planning_to_attack(state) — (lib_battle_ai)
   • nếu không còn untriggered attacker trên omega_front_line:
     → omega_end_turn: alpha_defending=false · alpha rút bài ngẫu nhiên
     → client: omega_turn_end:turn · next_move = "alpha_turn"
   • nếu còn attacker: lên kế hoạch tấn công cho vòng tiếp
↑ quay lại Alpha Turn Loop
khi HP ≤ 0 hoặc client kết thúc
🏁 Kết thúc
battle_end
• determine_winner: alpha_hp > omega_hp → "alpha", ngược lại → "omega"
• end_session: đóng battle session
• nếu winner = "alpha" → open_drop_packs → output.drops
• output: session_id · status="ended" · winner · turn · alpha_hp · omega_hp

battle_debug_turn
chỉnh HP thủ công (dev only)
target: "alpha"|"omega" · hp: +heal / -damage

⚠ Cảnh báo

card_deploy.lua — file bị mất, chỉ còn .meta. Script này từng tồn tại nhưng đã bị xóa hoặc chưa được tạo lại.
omega_defending — được check trong alpha_attacking nhưng chưa có script nào set nó thành true. Cần tạo cơ chế để bật omega_defending trước khi alpha có thể tấn công.
